## Project Overview
This project analyzes the relationship between salary transparency and workforce demographics to understand patterns of pay equity in the technology industry.

## Files Included
- analysis.py – Python script for data cleaning, analysis, and visualization
- salary_dataset.csv – raw salary dataset
- diversity_dataset.csv – raw diversity dataset
- salary_dataset_cleaned.csv – cleaned salary dataset
- diversity_dataset_cleaned.csv – cleaned diversity dataset
- salary_distribution.png – salary distribution graph
- diversity_distribution.png – diversity graph
- salary_missing.png – missing values graph

## Metrics Computed
- Adjusted Pay Gap (APG)
- Data Consistency Score
- Audit Flag Density

## Description
The Python script performs:
- Data cleaning and preprocessing
- Salary normalization
- Outlier detection
- Metric computation
- Graph generation
